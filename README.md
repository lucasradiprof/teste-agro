# 🌱 Agro Forte — Futuro Sustentável

Projeto de blog com visual neon desenvolvido em HTML, CSS e JavaScript.

Tema:
**“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

---

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

---

## 🎨 Visual

- Estilo neon futurista
- Responsivo
- Interface moderna
- Efeitos glow
- Design sustentável/agrotech

---

## 📂 Estrutura

```bash
agro-forte-blog/
│
├── index.html
├── style.css
├── script.js
└── README.md
````

---

## ▶️ Como executar

1. Baixe os arquivos
2. Abra a pasta do projeto
3. Clique em `index.html`

Ou utilize a extensão Live Server no VS Code.

---

## 🌎 Publicação no GitHub

1. Crie um repositório no GitHub
2. Envie os arquivos
3. Vá em:

Settings → Pages

4. Em "Branch", selecione:

```bash
main
```

5. Clique em Save

Seu site ficará online gratuitamente com GitHub Pages.
